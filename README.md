# PayFlow Solutions - Incident Analysis & Secret Management

## Contexto del Proyecto
PayFlow Solutions opera una infraestructura crítica de procesamiento de pagos y transferencias financieras interbancarias (SPEI). Se identificó una brecha de seguridad donde claves privadas de firma de tokens y secretos de API de conexión bancaria se filtraron en repositorios no controlados durante 72 horas.

## Objetivo de la Actividad
El equipo debe analizar los impactos de esta filtración, evaluar los vectores de exposición, diseñar un plan de respuesta a incidentes inmediato y proponer una arquitectura segura basada en gestión centralizada de secretos.
